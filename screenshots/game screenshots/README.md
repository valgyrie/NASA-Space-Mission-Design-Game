# Game screenshots

The game as it is now, one picture per main screen. The main [README](../../README.md) shows these.

| Picture | What it shows | How to get there |
|---|---|---|
| [title.jpg](title.jpg) | The title screen and main menu, SLS waiting on the pad behind it | Open the game |
| [exit.jpg](exit.jpg) | Exit: the browser kept the tab open, so the sheet says the Companies are saved and how to stop LEAP | Main menu → Exit |
| [new-company.jpg](new-company.jpg) | Starting a Company: name, Seed, a real place on the globe, Campaign or Free Play, Explorer or Mission Director | Main menu → Play (with no saved Company), or Play → Create new Company |
| [site.jpg](site.jpg) | The Demo Site in January 1958: Mines and factories on the coast, Raw Materials and money on top, the Build menu below | Main menu → Demo Mode → Era 1 |
| [designer.jpg](designer.jpg) | The Mission Designer's Check step for Explorer 1, every bar in the green, in Explorer mode | Same → Mission Designer → last step |
| [planner.jpg](planner.jpg) | The Launch planner's Rocket step for Apollo 11's science package: Saturn V on its pad, the other rockets locked or retired (Explorer mode) | Demo Mode → Era 3 → Mission Designer → Plan the Launch |
| [launch-sls.jpg](launch-sls.jpg) | Liftoff of SLS from Pad 39B, carrying the Company's CubeSat on Artemis II | Demo Mode → the Artemis Era → ship and launch |
| [moon-apollo-11.jpg](moon-apollo-11.jpg) | Apollo 11 on the Moon: the crew sets up the science package beside the Lunar Module | Demo Mode → Era 3 → ship and launch; the Moon sequence after the climb |
| [anomaly.jpg](anomaly.jpg) | Explorer 1 in orbit: the "Point the antenna" Anomaly, the first one in a game, which can't be skipped | Demo Mode → Era 1 → ship, then Launch; it comes during the Mission days |
| [report.jpg](report.jpg) | The Mission Report for Explorer 1 in Explorer mode, scrolled down: the first Mission Patch, what happened, the trouble in space, the real Explorer 1 | Demo Mode → Era 1 → ship, Launch, play the Anomaly, wait for the Mission to end (or Skip to the report) |
| [minigame.jpg](minigame.jpg) | Lost Signal, a Mission Director mode Minigame, at its start: the loss-of-signal checklist, the receiver and the Deep Space Network | Main menu → Minigames → Mission Director → Start (the order of the three games is random) |

`launch-sls.jpg` and `moon-apollo-11.jpg` were taken on 15 Nov 2026 for the project description (`docs/submission/figures/`); the rest were taken the same evening on `main` at e1fef1b. Taken at 1280×800 in a headless browser with software rendering, so they show the look, not the frame rate.
