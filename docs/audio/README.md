# Audio

Where the game's music and sound effects come from, and how they're credited.

## Order of preference

1. **Free licensed audio** (CC0 / public domain first). Check the licence on the actual page before using anything.
2. **Generated by us:** sound effects synthesised in code; music generated with Lyria 3.5 using [`music-prompts.md`](music-prompts.md).
3. Everything used goes in the credits table below and on the in-game Credits screen.

## Sound effects

- **Generated in code** (Web Audio): UI clicks and hovers, beeps, alarms, countdown ticks, coin/reward chimes, building placement, launch rumble, radio static.
- **Recorded, if code sounds aren't good enough:** [Kenney.nl](https://kenney.nl/assets/category:Audio) audio packs (CC0).

## AI-generated music

- Made with **Google Lyria 3.5** in Gemini. Every file carries Google's inaudible SynthID watermark.
- Credit line in game: _"Music generated with Google Lyria 3.5."_
- Before publishing, check Google's current terms for using Gemini-generated music.

**All tracks:**
- **Volume is consistent** (within about 2 LU), and there's no audible clipping.
- **Peaks are slightly above 0 dB**, which can crackle on some devices. Fix: normalise every track to −16 LUFS with peaks ≤ −1 dB.
- **Loops all fade out** (Lyria ignored "no fade-out", as expected). Fix: cut before the fade and crossfade the end into the start in game.
- **26 MB is heavy for a web game.** Fix: re-encode to about 128 kbps (or Ogg/Opus) and load each track only when its screen opens.
- **Stingers:** the files in `public/audio/music/` are the approved short cuts; the 1-minute originals are in git history.

## Mastering (ticket 25, 2026-11-12)

`scripts/master_music.sh <originals> <output>` rebuilds every file in `public/audio/music/` from the originals (git history: `899a864`, stingers `ff21515`):

- **Loop cuts** (start–end, seconds): `site-calm-a` 0–165.5, `site-calm-b` 5.8–153.5, `designer-focus` 0–117, `flight-orbit` 2–153.5, `anomaly` 13–58. Chosen from the level every half second, just before each fade-out. The game starts the next play 3 s before the end and crossfades.
- **Loudness:** two-pass normalisation to −16 LUFS; measured −16.2 to −16.4 LUFS, true peaks −1.4 dB or lower.
- **Encoding:** 128 kbps MP3, 44.1 kHz. 26 MB down to 15 MB. Each track loads only when its screen opens.
