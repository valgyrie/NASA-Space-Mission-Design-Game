# Audio

Where the game's music and sound effects come from, and how they're credited.

## Order of preference

1. **Free licensed audio** (CC0 / public domain first). Check the licence on the actual page before using anything.
2. **Generated by us:** sound effects synthesised in code; music generated with Lyria 3.5 using [`music-prompts.md`](music-prompts.md).
3. Everything used goes in the credits table below and on the in-game Credits screen.

## Sound effects

- **Generated in code** (Web Audio): UI clicks and hovers, beeps, alarms, countdown ticks, coin/reward chimes, building placement, launch rumble, radio static.
- **Recorded, if code sounds aren't good enough:** [Kenney.nl](https://kenney.nl/assets/category:Audio) audio packs (CC0).

## AI-generated music

- Made with **Google Lyria 3.5** in Gemini. Every file carries Google's inaudible SynthID watermark.
- Credit line in game: _"Music generated with Google Lyria 3.5."_
- Before publishing, check Google's current terms for using Gemini-generated music.
