# Audio

Where the game's music and sound effects come from, and how they're credited.

## Order of preference

1. **Free licensed audio** (CC0 / public domain first). Check the licence on the actual page before using anything.
2. **Generated by us:** sound effects synthesised in code; music generated with Lyria 3.5 using [`music-prompts.md`](music-prompts.md).
3. Everything used goes in the credits table below and on the in-game Credits screen.

## In the game (ticket 25, 2026-11-12)

The ten team tracks are now 128 kbps, 44.1 kHz stereo MP3s: **14,732,651 bytes** in total, down from 24,025,515 bytes before this ticket (38.7% smaller). Music loads only after a user gesture and only for the current screen; the Site preloads its alternate track. Decoded tracks from other screens are released. A missing file, unsupported Web Audio or denied autoplay leaves the game playable.

The five loop files are trimmed to the approved windows above. Web Audio schedules a 3-second linear overlap on the audio clock, before either end reaches its old fade-out. Site A and B alternate. The other tracks play once per screen entry. The approved short stinger files are retained in full: decoded lengths 10.6 s and 8.5 s, including their approved fades. No one-minute stingers were restored.

Menu and Company setup use the menu theme; the Site and its side panels use the Site pair. Design, Launch planning and Test Run use designer-focus; countdown/climb use launch; orbit and Space view use flight-orbit. Anomalies use anomaly; Mission Reports use the matching stinger; Era and Real History cards use era-history. Closing an overlay restores the screen underneath. Hidden tabs suspend audio and clear future loop scheduling; returning restarts the current cue. Music runs at normal speed when the Game date or Launch show is sped up.

**Sound** controls in the main and pause menus set independent music/effects volumes; 0 mutes that channel. Settings stay in this browser (`leap.audio`), outside Company, Demo Mode and cloud saves. Defaults: music 50%, effects 70%. Audio credits in both menus list every music file and the code-generated effects.

**Rebuild:** use the received originals from commit `87a6b1a` (including its approved short stingers), in a separate directory, then run `python scripts/prepare-music.py ORIGINAL_DIRECTORY`. Requires ffmpeg/ffprobe, no Python packages. The script applies the approved trims, measures integrated gain, preserves the original dynamics, limits only when needed, encodes at 128 kbps and checks the encoded result. It calibrates from the original input, never by repeatedly re-encoding its output. The ledger is regenerated with file hashes. Do not pass the prepared output directory as input.

**Effects credit:** `src/audio/sound.ts` is original code for LEAP. Web Audio oscillators and filtered generated noise make the effects at runtime; there are no external samples or extra audio files. In-game credit: “Sound effects created in code for LEAP using Web Audio.”

**Checked:** all 340 tests and client/backend type checks pass, as does the production build. Four focused tests cover settings, cue coverage, prepared-file hashes/measurements/credits and approved cuts. Chromium checks at 1280×800 and 1024×768 cover gesture gating, cue changes, volume/mute persistence, one-shot completion, a real audio-clock loop seam, background suspend/resume, placement, Launch/Anomaly/report/history/Space-view cues and graceful failure without audio. All six effects render nonzero bounded waveforms in OfflineAudioContext. A shortened buffer fixture exercises the actual loop scheduler without waiting several minutes; its seam has overlapping voices, nonzero RMS and no clipping. Production-build success and failure Missions use prepared saves with assembly/Shipping advanced to clear weather; both play the correct stinger, and success opens the history cue. No application page errors in completed checks. Listening on speakers/headphones, Safari/Firefox, touch and real-device performance remain team checks. Launcher checks remain deferred to the final ticket.

**Mix (2026-11-13):** music plays at the slider level × `MUSIC_GAIN` (1), effects at × `EFFECTS_GAIN` (0.5), both in `src/audio/tracks.ts`. At the default 50%, music is about −22 LUFS. The earlier 0.6 music gain left it near −26 LUFS, which players heard as no music.
